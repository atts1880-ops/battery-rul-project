# NASA ALT26源域接入结果

NASA官方26组加速寿命电池包已经完整下载、流式解析并接入现有
V1.0/16维特征/TCN24/B_stats38迁移管线。

## 数据审计

| 项目 | 结果 |
|---|---:|
| 原始电池包 | 26 |
| 有效参考放电曲线 | 395 |
| 严格80% SOH EOL参考 | 12包、236行 |
| 右删失SOH/SSL | 8包 |
| 参考曲线不足 | 6包 |
| 拒绝参考曲线 | 15 |
| ALT26严格EOL范围 | 201.99～540.85 EFC |
| 合并后严格源池 | 17设备、438行 |

SOH定义为参考放电容量除以同一电池包首个有效参考容量。EFC由全寿命
放电Ah吞吐量除以首容量得到。只有平滑容量曲线实际跨过SOH=0.80且
截至交点至少有8条诊断曲线的电池包才拥有RUL标签。

## 防负迁移处理

ALT26严格寿命明显长于Basilisk约50～122 EFC的目标范围。训练入口因此：

1. 在内层目标验证设备上选择源寿命区间；
2. 对超过源寿命上界或低于源寿命下界的目标预测同时降低迁移权重；
3. 内层未改善至少0.1 EFC时自动把融合权重回退为0；
4. 不访问80台开发验证集和任何sealed标签。

## 冒烟结果

40台目标设备、两外折、种子52的代码路径测试：

| 方法 | RUL MAE (EFC) |
|---|---:|
| target_ssl_bstats | 13.3556 |
| target_reference_control | 13.3230 |
| NASA全源均匀分支 | 13.3556 |
| NASA内层自适应源筛选 | 12.6119 |

冒烟实验只用于证明数据、模型、源筛选和泄漏审计能够端到端运行，不能
替代320设备、5折、3种子的正式OOF显著性实验。

## 正式严格OOF结果

正式实验覆盖320台目标训练设备、5个外折和种子52/53/54，共22,185个
三种子集成样本点。80台开发验证设备和sealed集合均未访问。

| 方法 | RUL MAE | RMSE | 偏差 | P90绝对误差 | 最差设备MAE |
|---|---:|---:|---:|---:|---:|
| target_ssl_bstats | 4.9054 | 6.6100 | -0.3173 | 10.7004 | 16.0113 |
| NASA全源均匀分支 | 4.7537 | 6.3203 | 0.5270 | 10.1109 | 15.5899 |
| NASA内层自适应筛选 | 4.5426 | 6.0086 | 0.3051 | 9.6679 | 14.5738 |
| 目标参考控制 | **4.4184** | **5.8530** | 0.0906 | **9.5741** | 15.2322 |

NASA自适应方法相对`target_ssl_bstats`降低RUL MAE 7.40%，配对设备
bootstrap的候选减基线误差差为-0.3629 EFC，95%区间
[-0.5341, -0.1947]，因此相对该target-only/SSL基线存在显著正迁移。

但NASA方法比同参数量目标参考控制高0.1242 EFC（恶化2.81%），bootstrap
95%区间为[0.0443, 0.2018]。因此它没有证明跨域信息优于新增目标参考
机制，预注册的总体验收保持未通过，也没有解锁开发验证集或sealed评估。

三个种子的NASA自适应MAE分别为4.7300、4.7958、4.7128 EFC；三个种子
均优于各自的target_ssl基线，但均未优于目标参考控制。15个内层策略中
全部至少选择了一个ALT26设备，中位选择12个源，中位有效融合权重为0.5。

困难区间也得到改善：

- 当前EFC不高于15：8.0339降至6.7308 EFC；
- 真实RUL大于60：8.0976降至6.8059 EFC；
- 长寿命Q4偏差绝对值相对target_ssl改善40.18%。

正式产物位于`nasa_external_sources/expanded_source_formal`。
