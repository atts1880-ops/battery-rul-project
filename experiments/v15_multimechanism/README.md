# V1.5 多退化机理研究

该分支研究模型能否在不知道目标数据版本的情况下，同时适应 V1.0 与 V1.5 及其多机理微域。它不是根目录最终提交模型，现有两组正式筛选均未达到晋升条件。

- `generalization/`：双域平衡训练、参数匹配控制和四专家因果软门控；
- `continual/`：从 V1.0 父模型继承参数，依次加入 V1.5 桥接域及四个微域，并比较普通继承微调、MLDG、GroupDRO 与 SWAD。

数据域标识只用于采样、损失分组和结果统计，不进入模型输入。未来曲线、真实 SOH/RUL/EOL、knee 真值和内部机理标签均不能作为在线输入。

本目录不包含 V1.5 validation、伪盲测设备或微域锁定测试数据。根目录已经提供 V1.0 和 NASA5 数据；V1.5 数据需按准备脚本单独生成或放置，并通过命令行参数传入。
